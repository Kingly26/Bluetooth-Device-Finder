# Bluetooth-Device-Finder

App Android (sul telefono si chiama **BT Finder**) per ritrovare cuffie, PC, telefoni e qualsiasi dispositivo Bluetooth che trasmette in zona, con un radar a cono che stima la direzione. Solo locale: nessun server, nessun account.

Push su `main` → GitHub Actions compila l'APK → lo scarichi da *Actions › ultima esecuzione › Artifacts › Bluetooth-Device-Finder-apk*.
